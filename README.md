# Moswax POS - Product Specification

**Moswax POS** is a web-based Point of Sale system designed for multi-store retail operations. This repository contains the full product specification, UI structure, and technical requirements for Version 1.0.

## 🚀 Project Overview
- **Type:** Web-based POS System
- **Scope:** Multi-store support
- **Version:** 1.0 (MVP)
- **Status:** Specification Phase

## 👥 User Roles
1. **Admin:** Full system access, user management, multi-store oversight.
2. **General Manager:** Regional oversight, reporting, checkout access.
3. **Inventory Manager:** Product management, stock adjustments, purchasing.
4. **Supervisor:** Shift management, voids/discounts, store reporting.
5. **Cashier:** Checkout, shift handling, basic sales views.

## 🛠 Key Features (v1.0)
- [x] Sales Checkout (Multi-payment support)
- [x] Product & Inventory Management
- [x] Receipt Printing (Web-based)
- [x] Reporting & Analytics
- [x] User & Role Management
- [x] Multi-store Architecture
- [ ] Returns/Exchanges (Excluded in v1)
